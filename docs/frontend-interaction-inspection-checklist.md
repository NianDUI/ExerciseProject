# 前端交互巡检清单（基于 docs 文档）

适用依据：
- `docs/frontend-page-api-field-mapping.md`
- `docs/openapi-frontend-separation.yaml`

目标：
- 验证前端页面交互、接口联动、字段映射、鉴权流程与异常处理是否符合文档约定。

## 1. 巡检准备

- 环境：`dev` 配置可用，数据库有基础数据（站点/配置/书籍/章节各至少 1 条）。
- 账号：准备一份有效明文 token（用于前端加密后发送）。
- 浏览器：Chrome 最新版，开启 DevTools（Network + Console）。
- 页面范围：
  - 旧版：`/main` 与其子页面
  - 新版：`/modern/main` 与其路由页面（如已启用）
  - 移动端：`/m/list.html`

## 3. 核心巡检项（P0）

### 3.1 鉴权与公共协议

- `C-01` token 首次输入与加密存储
  - 步骤：清空 Cookie/SessionStorage，进入任一需要接口调用页面，触发请求。
  - 预期：弹窗输入 token；请求头出现 `token`；本地存储有加密 token；接口返回 `code=200`。

- `C-02` token 失效提示
  - 步骤：手工篡改 token 后刷新页面并触发接口。
  - 预期：后端拒绝；前端出现明确错误提示；页面不出现静默失败。

- `C-03` 统一响应处理
  - 步骤：构造一个后端返回 `code!=200` 的请求（如非法参数）。
  - 预期：前端统一弹错误消息，不进入成功分支。

### 3.2 主导航与入口

- `C-04` 旧版首页入口
  - 步骤：访问 `/main`，点击站点/书籍/配置/文件/日志/新管理后台入口。
  - 预期：均能跳转到对应页面，无 404。

- `C-05` 新版首页入口（如启用）
  - 步骤：访问 `/modern/main`，点击左侧菜单与顶部“旧版首页”。
  - 预期：路由跳转正常；可返回旧版。

### 3.3 CRUD 主链路

- `C-06` 站点列表查询与分页
  - 步骤：站点列表输入关键词搜索、翻页、改每页条数。
  - 预期：请求参数包含 `name/pageNum/pageSize`；列表刷新正确。

- `C-07` 站点新增与编辑
  - 步骤：新增站点并保存；编辑已存在站点并保存。
  - 预期：新增时 `siteid=null`；编辑时带 `siteid`；保存后列表可见变更。

- `C-08` 配置新增/编辑/复制
  - 步骤：新增配置；编辑配置；从列表点击复制后保存。
  - 预期：复制模式提交 `configid=null`；其余字段正确复制。

- `C-09` 书籍新增/编辑与 handlerinfo
  - 步骤：新增书籍并填写处理参数；再编辑该书籍。
  - 预期：`handlerinfo` 为合法 JSON 字符串；编辑页可正确反序列化回填。

- `C-10` 章节编辑与查看
  - 步骤：编辑章节后进入查看页，切换上一章/下一章。
  - 预期：内容展示正常；前后章切换可用；无脚本报错。

- `C-11` 批量删除
  - 步骤：在站点/书籍/配置/章节列表勾选多条批量删除。
  - 预期：请求路径为逗号分隔 id；删除成功后列表刷新。

## 4. 重点业务巡检项（P1）

### 4.1 章节任务流

- `C-12` 重新获取全部
  - 步骤：章节页点击“重新获取”。
  - 预期：触发 `/api/reacquireAllChapter/{bookid}`；进入轮询刷新状态。

- `C-13` 获取后续
  - 步骤：章节页点击“获取后续”。
  - 预期：触发 `/api/getFollowUpChapter/{bookid}`；轮询刷新。

- `C-14` 获取指定和后续
  - 步骤：输入章节链接后提交。
  - 预期：触发 `POST /api/getSpecifiedAndFollowUpChapter`，请求体含 `{bookid,url}`。

- `C-15` 停止获取
  - 步骤：任务运行时点击“停止获取”。
  - 预期：调用 `/api/stopGet/{bookid}`；轮询停止；按钮状态恢复。

- `C-16` 单章刷新
  - 步骤：章节行点击“刷新”。
  - 预期：触发 `/api/reacquireSingleChapter/{chapterid}`，且仅影响目标章节。

- `C-16A` 章节轮询追最新页（与旧版一致）
  - 步骤：触发任一抓取任务后，停留在章节列表中观察轮询过程。
  - 预期：轮询刷新时会拉取最新页（等价旧版 `pageNum=9999999` 行为），新章节出现后无需手动翻页即可看到。

### 4.2 文件与日志

- `C-17` 文件目录浏览
  - 步骤：访问 `/file/list/**` 多级目录。
  - 预期：目录列表展示正确，路径跳转正确。

- `C-18` 文件下载与播放
  - 步骤：下载文件；打开视频文件。
  - 预期：`/api/file/download/**` 可用；视频可播放并自适应。

- `C-19` 日志 WebSocket
  - 步骤：打开日志页，观察连接、滚动、断开。
  - 预期：连接后发送 token；持续收日志；最多保留约 200 行；关闭页后断开连接。

### 4.3 移动端链路

- `C-20` 移动端书籍->章节->段落
  - 步骤：`/m/list.html` 进入书籍、章节、段落并翻页。
  - 预期：接口分别命中 `queryBookList/queryChapterList/queryChapterInfo`；标题与分页正确。

- `C-20A` 新版首页入口补齐
  - 步骤：进入新版仪表盘，点击“移动端书籍”和“IVI测试频道列表”。
  - 预期：
    - “移动端书籍”跳转 `/m/list.html`
    - “IVI测试频道列表”以新窗口打开 `http://ivi.bupt.edu.cn`

## 5. 兼容与异常巡检项（P2）

- `C-21` 空数据页面
  - 步骤：搜索一个不存在关键词。
  - 预期：空态文案显示，不报错。

- `C-22` 边界分页
  - 步骤：跳转最后一页后删除数据，再刷新。
  - 预期：页码自动回退到有效页，页面可继续操作。

- `C-23` 表单非法输入
  - 步骤：输入非法数字、空必填项、非法 URL。
  - 预期：前端校验拦截；后端返回校验失败时前端有提示。

- `C-24` 网络抖动/超时
  - 步骤：模拟慢网或失败请求。
  - 预期：加载态可感知；失败提示清晰；页面可重试。

## 6. 接口契约抽检（建议至少 10 条）

- 抽检原则：
  - 每个模块至少 2 条（列表 + 保存）
  - 核对请求字段与文档一致
  - 核对响应结构必须为 `code/message/data`

- 推荐抽检接口：
  - `/api/querySiteList`
  - `/api/saveSite`
  - `/api/queryBookList`
  - `/api/saveBook`
  - `/api/queryConfigList`
  - `/api/saveConfig`
  - `/api/queryChapterList`
  - `/api/getSpecifiedAndFollowUpChapter`
  - `/api/queryChapterInfo/{id}`
  - `/api/queryGetStatus/{id}`

## 7. 通过标准

- P0 用例全部通过。
- P1 用例通过率 >= 90%，且无阻断缺陷。
- P2 不出现数据错乱、页面崩溃或安全问题。
- 接口契约抽检无结构性偏差（字段名、类型、分页语义一致）。

## 8. 缺陷分级建议

- S1：主流程不可用（无法登录鉴权、核心列表打不开、保存失败）
- S2：功能可用但结果错误（字段映射错、任务状态错、翻页错）
- S3：体验问题（提示不清晰、样式错位、弱兼容问题）
